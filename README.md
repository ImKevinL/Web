# Plataforma de Servicios de Streaming

Proyecto académico frontend desarrollado con HTML, CSS y JavaScript.
-🔗Demo en vivo: https://imkevinl.github.io/Web/


## 🎯 Objetivo
Aplicar lógica en JavaScript para la gestión de un carrito de compra y descuentos por combinación de servicios.

## ✨ Funcionalidades
- Catálogo de servicios de streaming
- Agregado y eliminación de servicios en el carrito
- Cálculo dinámico de precios
- Aplicación de descuentos por combos
- Sección de contacto

## 🧠 Lógica implementada
- Manejo de eventos en JavaScript
- Manipulación del DOM
- Cálculo de totales y reglas de descuento

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript

## ▶️ Ejecución
1. Clonar el repositorio
2. Abrir el archivo `index.html` en el navegador

## 📌 Aprendizajes
- Organización de lógica en JavaScript
- Separación entre estructura, estilos y comportamiento
- Mejora de la experiencia de usuario mediante interactividad
